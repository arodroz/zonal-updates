This website

This website is static. It sets no cookies, runs no analytics and loads nothing from other sites. It remembers your choice in the Key labels switch in your browser’s local storage, which is never sent anywhere.

The site is hosted on GitHub Pages, operated by GitHub, which logs visitors’ IP addresses for security, as described in the GitHub General Privacy Statement.
